# Dataset Audit Reports

This directory contains reproducible Markdown statistics reports for the raw datasets, generated by `scripts/audit_dataset.py`.

## How to reproduce

Run the following commands from the repository root using the project's `uv` environment. They regenerate the UA-DETRAC and CityPersons raw-dataset audit reports.

### UA-DETRAC (split-first layout)

```powershell
uv run --no-sync python scripts/audit_dataset.py --root data/raw/ua_detrac --layout split-first --splits train test --names-from data/raw/ua_detrac/data.yaml --out docs/data/audit_raw_ua_detrac.md --title "Dataset Statistics: UA-DETRAC"
```

### CityPersons (type-first layout)

```powershell
uv run --no-sync python scripts/audit_dataset.py --root data/raw/citypersons --layout type-first --splits train val test --names-from data/raw/citypersons/data.yaml --out docs/data/audit_raw_citypersons.md --title "Dataset Statistics: CityPersons"
```

## Notes

- `--layout` and `--splits` are required arguments (no defaults).
- If a requested split's image directory is missing, `audit_dataset.py` prints a warning to `stderr` and skips that split rather than emitting a misleading zero-statistics row.
- Dataset files themselves are not stored in this repository; see `data/README.md` for sources and download instructions.
